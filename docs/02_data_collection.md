# Data Collection

## Datasets Used

1. GDP per capita (World Bank)
2. Imports (% of ICT goods)
3. E-waste dataset (Kaggle)

## Data Sources

- World Bank

## Notes

- GDP and Imports datasets were in wide format
- Required transformation to long format
- E-waste dataset did not contain Sri Lanka data
- Used simulation approach by mapping another country to Sri Lanka
